📌 About
This is my personal developer portfolio, designed as a professional hub for recruiters, developers, and collaborators.

The portfolio follows a terminal-inspired developer aesthetic while maintaining a clean, responsive, and user-friendly interface. It highlights my technical journey, projects, skills, internships, certifications, and educational background.

✨ Features
🖥️ Terminal-Style UI — Developer-themed interface with terminal paths and code-inspired labels
📱 Fully Responsive — Optimized for mobile, tablet, and desktop
🧭 Smooth Navigation — Single-page navigation with section-based scrolling
📊 Animated Skill Bars — Visual representation of technical skills
🗂️ Project Cards — Projects presented using Problem → Build → Stack → Impact format
🏅 Certifications Section — Professional certifications and achievements
📄 Resume Download — Direct access to my resume
📬 Contact Form — Allows visitors to send messages through their email client
🔍 SEO Optimized — Includes Meta Tags, Open Graph, Twitter Cards, and JSON-LD structured data
🌙 Developer-Focused Design — Modern terminal-inspired visual experience

The portfolio is hosted on Netlify with continuous deployment connected to GitHub.

Whenever changes are pushed to the main branch, Netlify automatically rebuilds and deploys the latest version.

git add .
git commit -m "✨ Update portfolio"
git push origin main
🚀 GitHub → Netlify → Live Website
